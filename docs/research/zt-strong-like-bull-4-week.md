**Source:** Google Drive → Weightlifting → `ZT Strong Like Bull (4 week)` (shared by mkpenrod05@gmail.com)

- `Strong Like Bull - 2 .pdf` — Meso 2/4 (Week 2)

- `Strong Like Bull - 4 .pdf` — labeled "Meso 3/4" in the PDF body, but is positioned/named as Week 4 and is structured as a taper/competition week (see note at bottom)

**Length:** 4 weeks. Weeks 1–3 run a 5-day week (Day 1–5). Week 4 is a taper structured around days out from competition rather than a Day 1–5 pattern.

## How to read the "Basis" tags

Percentage-based sets are tagged `[Basis: <Exercise> max]` for the lift the percentage is calculated from. Where the source explicitly states the basis (e.g., "70% (of jerk)"), that's noted. Where a set is a fixed-load or self-referential drop set (e.g., "Find 1RM then 90% of that"), the basis is the same exercise, tagged "self."

## Notes / ambiguities for app design

- **Duplicate file:** `Strong Like Bull - 2 _copy.pdf` contains identical day-by-day programming to `Strong Like Bull - 2 .pdf` (same sets/reps/percentages), just a different PDF export (different file size/modified date). Treated as one program week here; the duplicate can likely be ignored or removed from Drive.
- **Week 4 label mismatch:** confirm with the source whether this is genuinely week 4 (taper) mislabeled as "Meso 3/4," or whether a true Meso 4/4 file is missing from the folder and this taper file is a bonus/appendix. Programmed here as Week 4 based on file ordering and content.
- **"Clean" vs "Clean and Jerk":** as in the other ZT programs, plain "Clean" percentages (Day 3/Day 4 work) are tracked against a Clean-only max, distinct from the Clean & Jerk max used for "Clean and Jerk" and wave-set lines.
- **"70% (of jerk)"**: this is the one place in the whole corpus where the source explicitly annotates the % basis inline — useful as a model for how the app might let users tag a set's basis lift explicitly rather than relying on inference from the exercise name.
