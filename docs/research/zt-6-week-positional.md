**Length:** 6 weeks. Most weeks run Day 1–6 (Day 3 is a recovery/cardio day, Day 6 is an "Athletic Power Day"). Weeks 5–6 diverge into a 6–7 day peaking structure with explicit rest days.

**Method:** This is a [Triphasic Training](https://en.wikipedia.org/wiki/Triphasic_training)-style block, structured in three 2-week phases:
- Weeks 1–2: **Eccentric phase** (slow lowering / eccentric emphasis)
- Weeks 3–4: **Isometric phase** (paused reps)
- Weeks 5–6: **Peak phase** (heavy singles / testing, normal tempo)

## How to read the "Basis" tags

Percentage-based sets are a percentage of some lift's max, not necessarily the exercise being performed. Every `%`-based line below is tagged `[Basis: <Exercise> max]` — the lift whose 1RM (or the rep-max established earlier that same session/week) the percentage is calculated from. Tags marked "(assumed)" aren't explicit in the source PDF and use standard weightlifting-programming convention; flag these for confirmation before building assumption logic in the app.

## Week 1 — Eccentrics Week 1/2

### Day 1
- **No Hook No Foot Snatch**: (70%/3)x3, (75%/3)x3 — `[Basis: Snatch max]`
- **Tempo Overhead Squat**: 10s standing OH, 10s eccentric, 10s pause, up fast. Build to 1RM with tempo. (session max, no basis)
- **Eccentric Snatch Pull**: drive elbows high on pull, then 10s eccentric, touch-and-go — (50%/3), (60%/3), (70%/3)x2 — `[Basis: Snatch max]`
- **Eccentric Back Extension**: unweighted, 3x10, 5s eccentric
- **Eccentric Hanging Leg Raise**: 3x8–12, 3s eccentric
- **Standing Side Crunch**: 3x10 each side, 5s eccentric

### Day 2
- **Touch and Go Split Jerks**: split jerk off rack, recover, lower under control, touch-and-go into next rep — (70%/5)x3, (75%/3)x3 — `[Basis: Split Jerk (jerk-from-rack) max]`
- **Eccentric Strict Press**: 5x5, 10s eccentric, start light and build over sets
- **Eccentric DB Bench Press**: 5x10, 5s eccentric, start light and build
- **Paired w/ Eccentric Pull-ups**: 5x5–8, 5s eccentric (concentric optional)
- **Eccentric French Press**: 3x10, 5s eccentric
- **Eccentric Bicep Curl**: 3x10, 5s eccentric
- **Eccentric Lateral Raise**: 3x10, 5s eccentric

### Day 3
- 1 hour low-intensity cardio: walk, bike, row, swim

### Day 4
- **No Hook No Contact Clean**: (70%/3)x3, (75%/3)x3 — `[Basis: Clean max (assumed — treated as distinct from Clean & Jerk max)]`
- **Tempo Front Squat**: 10s eccentric, 1s pause, up fast — (50–60%/3)x5, start at 50%, don't build past 60% — `[Basis: Front Squat max]`
- **Barbell Front Rack Bulgarian Split Squat**: 5x5 each leg, 5s eccentric
- **Barbell Glute Bridge**: start at 60kg, 4x8–10, 5s eccentric, build over sets
- **Sumo Deadlift**: start at 60kg, 4x8–10, 5s eccentric, build over sets

### Day 5
- **Block Snatch**: (70%/3)x3, (75%/3)x3 — `[Basis: Snatch max (assumed)]`
- **Block Clean and Jerk**: (70%/2+1)x5 — `[Basis: Clean & Jerk max]`
- **Eccentric Clean Pull**: drive elbows high, then 10s eccentric, touch-and-go — (50%/3), (60%/3), (70%/3)x2 — `[Basis: Clean max]`
- **Eccentric RDL**: 3x10, starting at 70% of clean max, 3s eccentric, build over sets — `[Basis: Clean max]` (explicit in source)
- **Eccentric Hamstring Curl**: 3x15–20, 3s eccentric

### Day 6 (Athletic Power Day)
- **Box Jumps**: 3x5
- **Rebounding Broad Jump**: 3x5
- **Jumping Lunge**: 3x6 each leg
- **Ball Slam**: 3x10
- **Squat Jump**: 3x10
- **Sprints**: 3x10m at 75–90% capacity (perceived effort, not load %)

## Notes / ambiguities for app design

- "Block Snatch" and "Block Clean and Jerk" percentages are never explicitly tied to a lift in the source; assumed to reference the standard Snatch / Clean & Jerk maxes (block variants are usually lighter, so this likely understates true block capacity).
- "Clean" (as in "No Hook No Contact Clean") is treated as its own max distinct from "Clean and Jerk" throughout — the program clearly separates clean-only work from full C&J work. The app will need a way to track a Clean-only PB separate from Clean & Jerk if this distinction matters.
- Several sets reference "last week's" established load/RM rather than a stored PB (e.g., Day 1 Week 4 Tempo Snatch Deadlift at "90% of last week's 5RM"). This is a session-to-session progression, not a percentage of an existing personal best — the app may need to support referencing a *previous workout's logged set*, not just a PB.
